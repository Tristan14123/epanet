# Self-hosted map glyphs (token-free labels)

- `Open Sans Bold/{0-255,256-511}.pbf` — vector glyphs for map labels.
- Source: https://fonts.openmaptiles.org (generated from Open Sans).
- License: Open Sans is under the Apache License 2.0
  (https://www.apache.org/licenses/LICENSE-2.0).

Ranges 0-255 (Basic Latin + Latin-1: e, e, a, c…) and 256-511
(Latin Extended-A: œ, Œ…) cover French labels.
